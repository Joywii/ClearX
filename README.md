# ClearX

ClearX 是一款只读 macOS 磁盘空间分析工具。当前版本仅在应用进程内缓存完整扫描结果，不写入本地数据库。

## 开发

使用 Xcode 打开 `ClearX.xcodeproj`，选择 `ClearX` scheme 后构建或运行。项目最低支持 macOS 14。
