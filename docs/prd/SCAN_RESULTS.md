# 扫描结果窗口

## 列表与大小

- 启动校验来源后尽快展示根目录真实条目，不等待后代大小统计或常规进度刷新周期。来源解析、首列和子列加载不使用骨架图或准备页；条目尚未可用时保持列布局空白，目录名称可先显示，未开始的大小留空。只有确认完整且可读的空目录显示“空文件夹”。

- 每列默认宽度为当前允许的最小宽度 220 pt，重置列宽也恢复到该宽度；保留独立拖拽调整及原有 220–1,080 pt 限制。

- 列表显示目录内容大小，按路径累计系统已分配字节；硬链接的每个路径都显示大小，首次或后续扫描顺序不影响目录归属。硬链接悬浮及无障碍说明为共享同一文件数据，不再显示为零或声称“不额外占用”。
- 工具栏提供按需打开的“大小统计”，展示当前显示快照的目录内容大小和全扫描硬链接去重大小。前者可重复计数，后者每个文件对象只计一次；两者均不是可释放空间，APFS 克隆及共享块不去重。局部不可读或取消显示部分结果，扫描中显示当前已统计量，重扫保留旧结果时明确为上次完整结果。不增加常驻顶部进度或底部提示。

- 大小显示按四舍五入最多保留一位小数，不补尾零；恰好为 5 时进位，例如 `1.25 GB → 1.3 GB`，而非银行家舍入。只改变展示精度，扫描聚合与排序仍使用原始整数字节。
- 参考 OmniDiskSweeper，使用紧凑单行：左侧右对齐大小，右侧名称和目录进入箭头，不再使用双行卡片和文件图标。
- 保留符号链接及跨文件系统挂载点，显示零计入大小；符号链接名称用斜体，挂载点用目录绿色。二者均不提供进入箭头或下一列，不跟随目标、不跨卷扫描；悬浮与无障碍说明解释跳过原因，不能误称为空目录、重复硬链接或权限失败。
- 大小使用 Apple 格式化 API。名称与大小统一着色：扫描中（含等待扫描）红色，扫描结束后目录绿色、文件正文色（浅色模式黑色，深色模式适配可读性），不按大小量级分色；选中行保留白字，不显示行内三角感叹号图标。尚未开始的目录大小留空。颜色之外通过悬浮说明和无障碍值表达状态。
- 扫描中显示已知后代大小，并随当前大小降序排列，同大小按本地化名称升序。重排不改变按节点 ID 保存的选择。
- 首屏 250 行，按需加载更多；每次刷新重取已加载前缀，不能因动态排序拼接出重复项。
- 不显示顶部普通扫描进度、当前路径或计数；工具栏保留取消扫描和重新完整扫描，扫描时不允许重复触发重扫。

## 条目右键菜单

- 同列 Command-click 切换选中，可取消全部选中；鼠标按下后纵向拖动选取起止行之间的连续范围，双指滚动仍为滚动。跨列选择清除上一批量选区，祖先路径高亮不参与批量操作。多选立即收起右侧列，恢复单目录后展开；单文件或零选中保持收起，拖选期间不展开目录。
- 拖选冻结当前列顺序，释放后恢复大小排序并按节点 ID 保持选区。边缘滚动仅经过已加载行，不自动加载后续页面；“加载更多”由用户主动触发。
- 左键点击某列空白处清空该列选择、收起右侧后续列，保留左侧祖先目录高亮；右键及 Control-click 空白处不弹菜单、不改变选区或导航。
- 当前窗口扫描或重扫期间隐藏“移到废纸篓”，无置灰项或相关提示；右键多选成员不弹菜单，单项目仍提供拷贝路径和 Finder 定位。扫描停止后恢复入口，包括取消、失败及不完整；重扫显示旧完整快照时仍按当前扫描状态隐藏。扫描结束不向已打开的菜单添加项目，开始重扫则关闭当前菜单，下次右键重新生成。
- 入口显示时，“移到废纸篓”在检查未完成、目标不可删除、扫描根、挂载点及含挂载点目录、废纸篓及内部内容、其他窗口相关扫描或文件操作进行中时置灰。任一目标被禁止则整批置灰，悬浮及辅助功能说明禁用原因；不静默过滤目标。
- 二次确认列出数量、名称、完整路径；取消为默认动作。说明目录包含未扫描及不可读内容、符号链接只移动链接本身、废纸篓不立即释放空间。目标固定，不随确认期间的选区变化。只调用系统移入废纸篓 API，绝不永久删除或提权。
- 执行前重验整批权限、挂载情况和文件身份，再逐项复核；单项失败继续其他项，支持停止剩余操作，不回滚。完成报告成功、失败、未处理数量及错误路径。成功后失效相关缓存并完整重扫受影响窗口，旧结果持续标记过期直到新完整扫描成功，取消或失败不能消除过期标记。

- 右键或 Control-click 单项弹出系统菜单，顺序为“拷贝路径”“在 Finder 中显示”“移到废纸篓”。右键多选成员仅提供整组选区的“移到废纸篓”；右键未选中项仅作用于该项，原选区不变。空白区域、空目录提示和加载更多按钮不提供此菜单。
- 操作对象是右键所在行，不是原先选中项。已选中 A 时右键 B，A 的选中状态及高亮全程不变，B 仅额外临时高亮；执行操作或取消菜单后仅取消 B 的临时高亮。右键 A 时，菜单期间及结束后 A 的选中状态及高亮均不变。临时高亮不赋予真实选中或无障碍选中语义；不展开右键目录、不收起已有后续列、不改变浏览位置。固定菜单打开时的节点 ID 与 URL，实时重排不改换目标。
- 拷贝绝对路径纯文本，保留空格、中文及特殊字符，不加引号、不做 Shell 转义、不使用 `file://`。符号链接复制自身路径，失效的快照路径也可拷贝；剪贴板写入失败时提示。
- Finder 打开所在位置并选中条目本身，不打开文件或进入目录。符号链接定位链接本身，包括仍存在的断链；挂载点只定位，不触发跨卷扫描。
- 点击 Finder 操作后在后台检查原路径。项目已删除、移动、磁盘卸载或无法定位时提示“项目已不存在或当前无法访问”，不回退父目录、不搜索同名项、不触发重扫。该提示是用户主动操作的局部错误，不改变扫描结果状态。
- 拷贝路径与 Finder 定位适用于文件、目录、包、符号链接、挂载点及其他已显示条目；扫描中、取消、不完整和显示旧快照时同样开放。辅助功能命名操作与菜单保持一致，扫描中不提供移到废纸篓。

## 异常与重扫

- 局部不可读不打断其他分支，仅在行内说明不完整，不显示每列底部提示；采用 OmniDiskSweeper 式的大小后缀 `+`，例如 `1.3 GB+`。尚未统计到可读大小时也保留 `+`，不能显示为普通零值；悬浮及无障碍说明继续解释未知或部分大小。不可读且无子项的列保持空白，不误标为“空文件夹”。
- 根目录不可用或整体失败才显示全局错误；取消显示明确的结束状态并停止所有计算中标记。
- 首次扫描的部分结果仍可浏览但不缓存。已有完整结果的重扫始终保留旧快照；候选成功才替换，取消、不完整或失败则明确说明仍显示上次完整结果。
- 旧快照不染成扫描中的红色，不暴露候选部分结果；失败重扫保留旧导航，成功切换快照重置旧节点选择。
- 除路径拷贝、Finder 定位及确认后移到废纸篓外，不新增完全磁盘访问请求、提权或被扫描文件操作。
