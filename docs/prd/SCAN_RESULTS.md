# 扫描结果窗口

## 列表与大小

- 启动校验来源后尽快展示根目录真实条目，不等待后代大小统计或常规进度刷新周期。来源解析、首列和子列加载不使用骨架图或准备页；条目尚未可用时保持列布局空白，目录名称可先显示，未开始的大小留空。只有确认完整且可读的空目录显示“空文件夹”。

- 每列默认宽度为当前允许的最小宽度 220 pt，重置列宽也恢复到该宽度；保留独立拖拽调整及原有 220–1,080 pt 限制。

- 列表显示目录内容大小，按路径累计系统已分配字节；硬链接的每个路径都显示大小，首次或后续扫描顺序不影响目录归属。硬链接悬浮及无障碍说明为共享同一文件数据，不再显示为零或声称“不额外占用”。
- 工具栏提供按需打开的“大小统计”，展示当前显示快照的目录内容大小和全扫描硬链接去重大小。前者可重复计数，后者每个文件对象只计一次；两者均不是可释放空间，APFS 克隆及共享块不去重。局部不可读或取消显示部分结果，扫描中显示当前已统计量，重扫保留旧结果时明确为上次完整结果。不增加常驻顶部进度或底部提示。

- 大小显示按四舍五入最多保留一位小数，不补尾零；恰好为 5 时进位，例如 `1.25 GB → 1.3 GB`，而非银行家舍入。只改变展示精度，扫描聚合与排序仍使用原始整数字节。
- 参考 OmniDiskSweeper，使用紧凑单行：左侧右对齐大小，右侧名称和目录进入箭头，不再使用双行卡片和文件图标。
- 保留符号链接及跨文件系统挂载点，显示零计入大小；符号链接名称用斜体，挂载点用目录绿色。二者均不提供进入箭头或下一列，不跟随目标、不跨卷扫描；悬浮与无障碍说明解释跳过原因，不能误称为空目录、重复硬链接或权限失败。
- 大小使用 Apple 格式化 API。名称与大小统一着色：扫描中（含等待扫描）红色，扫描结束后目录绿色、文件正文色（浅色模式黑色，深色模式适配可读性），不按大小量级分色；选中行保留白字，不显示行内三角感叹号图标。尚未开始的目录大小留空。颜色之外通过悬浮说明和无障碍值表达状态。
- 扫描中显示已知后代大小，并随当前大小降序排列，同大小按本地化名称升序。重排不改变按节点 ID 保存的选择。
- 首屏 250 行，按需加载更多；每次刷新重取已加载前缀，不能因动态排序拼接出重复项。
- 不显示顶部普通扫描进度、当前路径或计数；工具栏保留取消扫描和重新完整扫描，扫描时不允许重复触发重扫。

## 异常与重扫

- 局部不可读不打断其他分支，仅在行内说明不完整，不显示每列底部提示；采用 OmniDiskSweeper 式的大小后缀 `+`，例如 `1.3 GB+`。尚未统计到可读大小时也保留 `+`，不能显示为普通零值；悬浮及无障碍说明继续解释未知或部分大小。不可读且无子项的列保持空白，不误标为“空文件夹”。
- 根目录不可用或整体失败才显示全局错误；取消显示明确的结束状态并停止所有计算中标记。
- 首次扫描的部分结果仍可浏览但不缓存。已有完整结果的重扫始终保留旧快照；候选成功才替换，取消、不完整或失败则明确说明仍显示上次完整结果。
- 旧快照不染成扫描中的红色，不暴露候选部分结果；失败重扫保留旧导航，成功切换快照重置旧节点选择。
- 不新增完全磁盘访问请求、提权或被扫描文件操作。
