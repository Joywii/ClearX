# ClearX 路线图

## 当前实现

- SwiftUI macOS 应用与本地卷/文件夹选择。
- 只读目录扫描、多列浏览与文件/目录大小展示。
- 会话内存缓存与惰性列读取；扫描结果不写入 SQLite，退出应用后自动失效。
- 扫描、浏览和事件判定单元测试。

## 本期后续

- 接入设备级 FSEvents 流重放，并以高水位检查点驱动缓存复用或局部分支刷新。
- 将 GRDB 持久化快照作为可选缓存后端重新接入，并完成 1 GB 淘汰策略。
- 增加百万节点性能基准与真实磁盘回归测试。

## 非本期

- 文件清理、删除或移动。
- 网络卷、完全磁盘访问、App Sandbox 发布模型。

## 后续版本

- 安全清理：默认仅低风险项；高风险项需要二次确认与影响说明。
- 优先采用官方清理工具，所有处理限于本机。
- 开发者模式只统计依赖、lockfile、缓存和构建产物，不读取源码内容。
