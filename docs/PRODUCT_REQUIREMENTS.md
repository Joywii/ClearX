# ClearX 产品需求

## 定位

ClearX 是面向 macOS 的磁盘空间分析工具。启动即分析本机磁盘，通过 Finder 风格的多列浏览器定位大文件和目录；也可从文件菜单选择外接本地卷或任意文件夹，并在保护规则通过、二次确认后将选中项目移到废纸篓。

## 核心流程

1. 启动直接进入本机磁盘结果窗口并自动扫描，不展示扫描源选择页。本机磁盘固定为当前启动系统的根目录 `/`，不是卷列表首项或 APFS Data 卷入口；无法确认来源时显示错误并允许重试，不改扫其他位置。
2. 在独立结果窗口中浏览按大小排序的目录列。
3. 首次扫描显示渐进结果；同一应用会话内再次打开时先展示完整内存缓存。
4. 应用退出后不保留缓存；设备级事件校验和跨启动缓存复用属于后续版本。
5. 文件菜单提供“分析本机磁盘”和“分析其他磁盘或文件夹…”；后者按需打开扫描源选择窗口。
6. 同列支持 Command-click 与鼠标拖选，多选收起右侧列。结果行右键菜单提供“拷贝路径”“在 Finder 中显示”“移到废纸篓”；右键多选成员只提供整批移入废纸篓。右键本身不改变选区或导航，禁用策略与确认流程详见结果页需求。

## 页面目录

- 扫描源选择窗口，仅从文件菜单按需打开，不作为启动首页。
- 扫描结果窗口，交互详见 [扫描结果需求](prd/SCAN_RESULTS.md)。

MVP 允许复制路径、Finder 定位及确认后移入废纸篓；不提供文件打开、永久删除、清空废纸篓、任意移动、内容修改、提权、网络卷扫描或完全磁盘访问。
